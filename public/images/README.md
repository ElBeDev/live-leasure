# Imágenes de Destinos

Esta carpeta contiene las imágenes para el carrusel de destinos en la página principal.

## Imágenes requeridas:

Coloca aquí las imágenes con los siguientes nombres (formato .jpg):

1. **dubai.jpg** - Dubai, United Arab Emirates
2. **bali.jpg** - Bali, Indonesia  
3. **paris.jpg** - Paris, France
4. **cancun.jpg** - Cancún, Mexico
5. **tokyo.jpg** - Tokyo, Japan
6. **new-york.jpg** - New York, United States
7. **maldives.jpg** - Maldives
8. **rome.jpg** - Rome, Italy

## Recomendaciones:

- Resolución recomendada: Mínimo 800x600px (o mayor para mejor calidad)
- Formato: .jpg o .jpeg
- Peso: Optimiza las imágenes para web (máximo 500KB por imagen)
- Orientación: Las imágenes funcionan mejor en formato horizontal o cuadrado

## ¿Cómo agregar una nueva imagen?

Simplemente coloca la imagen en esta carpeta con el nombre correcto (ej: `cancun.jpg`) y automáticamente aparecerá en el carrusel.

## Imágenes temporales

Si aún no tienes las imágenes, la página mostrará imágenes de respaldo mientras las agregas.
